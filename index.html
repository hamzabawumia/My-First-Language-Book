For parents

This book deliberately has no written vocabulary. Point to a picture and say its name in the language you want your child to learn.

The first version uses friendly emoji as temporary artwork. The picture system is separated from the book, so custom illustrations can be added later without changing the app.

For best results, repeat familiar pictures often and use the same word consistently.
